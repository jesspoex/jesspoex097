# Audio assets

Drop `.ogg` files here with the exact names below. The game auto-loads any
that exist and silently skips missing ones (so it runs with no audio at all).

## SFX (res://assets/audio/)
- sfx_ball_drop.ogg   — ball lands in a tube (pitch randomized at runtime)
- sfx_ball_pick.ogg   — ball lifted off a tube
- sfx_level_win.ogg   — level complete fanfare
- sfx_hint.ogg        — hint reveal
- sfx_undo.ogg        — undo
- sfx_restart.ogg     — restart level
- sfx_fish_add.ogg    — a fish enters the aquarium ("bloop")
- sfx_reward.ogg      — daily reward claim ("ka-ching")
- sfx_gift.ogg        — surprise gift box ("ta-da")
- sfx_ui_tap.ogg      — button tap (soft)
- sfx_error.ogg       — invalid move (playful, not annoying)

## Music (res://assets/audio/)
- music_menu.ogg      — lo-fi / ambient for home + aquarium
- music_play.ogg      — light upbeat for puzzle play

## Free sources (commercial OK)
- SFX: freesound.org (CC0), kenney.nl, sfxr/bfxr generators
- Music: YouTube Audio Library, Pixabay Music, Incompetech (Kevin MacLeod)
